# Milestones

## v0.9.0 Transom 0.9.0: first public release (Shipped: 2026-11-08)

**Phases completed:** 11 phases, 162 plans, 241 tasks

**Delivered:** the first public Transom release (GitHub Releases, Developer ID signed and notarised DMG). Drag-to-dock nested tiling with crash-safe restore, a snapshot zoom camera, trackpad gestures, an overview with a Spaces bar, tab groups, saved views with `transom://` URLs and a CLI, window behaviour options, and Settings, onboarding, launch at login and an update check.

**Highlights:**
1. Headless `TransomModel` layout tree with undo, JSON migration (schema 1 to 5) and water-filled minimum sizes (Phase 1)
2. Non-blocking Accessibility window control with a classifier and private-API fallbacks (Phase 2)
3. Drag-to-dock tiling, reflow, gaps and crash-safe restore that works with zoom and Screen Recording off (Phase 3)
4. Zoom camera, gestures, overview/Spaces/displays, tab groups and saved views (Phases 4-8)
5. Desktop tile removed: docked windows fill the screen, floaters act like normal macOS windows (Phase 8.1.1)
6. Settings, onboarding, launch at login, GitHub Releases update check, notarised DMG (Phase 9)

**Stats:** 1,319 commits, 2026-10-23 to 2026-11-07; about 35,700 lines of Swift in `Sources` (78,400 with tests). Requirements 91/91 (93 IDs; TILE-15 superseded, ZOOM-11 retired).

**Release tag:** `v0.9.0` already existed (the published GitHub release on main), so this close created no tag.

**Closeout:** override_closeout. Status tech_debt accepted by the user (see `milestones/v0.9.0-MILESTONE-AUDIT.md`). Phases 1-8.1.1 read verification `stale` because later phases edited covered files; each affected requirement was re-verified later.

**Key accomplishments:**
- Swift 6 package with a flat, validated `LayoutTree`. You can dock a window on any edge (n-ary on the same axis), resolve the tree into whole-point rects with gaps, store it in a `DeskKey`-keyed `World`, and round-trip it through deterministic `schemaVersion: 1` JSON. Every malformed tree is rejected with a typed `LayoutError`.
- Window removal with i3-style proportional redistribution, a D-06 normaliser (collapse, same-axis merge, renormalise, minWeight clamp) run by every edit, two-neighbour boundary reweighing, and a 20-seed edit fuzz suite
- resolve now water-fills minimum sizes, reports windows that cannot fit as unfit (greedy removal plus re-admission), skips absent/fullscreen windows while keeping their slots, and rejects NaN/negative/out-of-range input. DropZones hit-tests resolved leaf rects for tile edge/centre, layout edge and empty-layout targets.
- Every desk now has a floating Desktop layer next to its tile tree. All desk edits go through one transactional `World.edit` funnel that keeps 50 undo levels per desk. Loading is hardened: a 16 MiB cap, a refusal for newer schema versions, a step-by-step `MigrationChain` for older ones, and a 17-item corrupt-file corpus that throws instead of crashing.
- Tab-group tiles (`group`/`selectTab`), lifecycle `setState` that keeps absent and fullscreen windows in their reserved slot until `.closed`, and `applyDrop`, proven end-to-end by a hit test → edit → resolve → undo → JSON scenario through `World.edit`.
- PaneEngine target with the draft async WindowSystem protocol, plus a no-AppKit import check enforced by every `swift test` and by a macos-26 GitHub Actions workflow
- A fixture window travels fixture -> per-app AXAppThread -> batched AX snapshot plus dlsym'd `_AXUIElementGetWindow` -> pure WindowTracker -> AXWindowSystem cache, with its real CGWindowID, pid and frame. A FakeWindowSystem runs the same tracker over a simulated OS, and a fixture app with every window shape takes stdin commands.
- Pane is now a menu-bar app: a `rectangle.split.2x1` template status item whose menu reads "Tracking N windows in M apps" from the live inventory, with the Window ID capability under Debug. XcodeGen builds it as a Developer-ID-signed, hardened `Pane Debug.app` (com.eightabyte.pane.debug) or `Pane.app` (com.eightabyte.pane, no get-task-allow), launched through LaunchServices.
- A pure classifier decides dockable, never-dock (with reason) or not-a-window from an AX snapshot plus the CG window layer. The tracker applies it with a 250 ms settle delay and sticky kinds, so minimising, hiding or a sheet never demotes a window. A `pane-dump` CLI recorded 11 redacted, human-labelled windows of real apps, and the classifier is tested against them. The corpus already caught one case: LibreOffice's Start Center.
- `LifecycleSync` sends OS lifecycle events into the model only through `World.apply`, and re-queries every window an undo brings back through `WindowSystem.windowInfo`, closing the Phase 1 obligation from c403f45.
- A pure PermissionReducer drives a "Set Up Pane" window and status menu: macOS's prompt appears once per grant cycle, a 1 s poll and Finder AXRole probe confirm access, and both stale forms (trusted-but-refused and the 15 s "Already turned on?" case) get a one-click fixed-argv tccutil reset.
- Live tracking: NSWorkspace lifecycle and per-window AX notifications drive per-pid cancel-latest refreshes (75 ms, 250 ms settle follow-up, 5 s sweep), and every window is keyed to a display UUID through one tested coordinate flip
- A frozen app is marked degraded after 2 consecutive -25204 results or one job over 1.5 s. From then on Pane only probes its AXRole every 2 s, and the first fast answer brings it back. Every other app keeps being tracked at full speed, which a SIGSTOP integration test checks.
- A live SwiftUI Tracked Windows table (ten UI-SPEC columns, footer, no-permission/loading/empty states) fed from the status item's single event reader, a UserDefaults exclusion list behind "Don't Arrange “App”" and "Never Arrange", and a Debug-only Freeze test that persists the pid before SIGSTOP and resumes it after 10 s, on quit and at every launch.
- Pane now treats a window as closed only when two sources agree: AX says the element is gone (-25202) or NSWorkspace says the app quit, and the window has left the CG list. Timeouts, frozen apps, the lock screen and sleep never remove a window, and reconciliation pauses while the Mac is locked or asleep, with one full refresh 1.5 s after it wakes.
- A natively tabbed window counts as one window. A pure `TabGroupTracker` builds each group from the visible tab's AXTabGroup count plus its offscreen CG siblings, and keeps the first-seen tab's identity. WindowTracker follows the visible tab through `visibleMemberID`, so a tab switch or a closed tab never reads as one window closing and another opening.
- Without `_AXUIElementGetWindow`, Pane matches each AX window to its same-pid CG window by frame (then CG title), gives stable synthetic `0xF000_0000 | n` IDs only when that is ambiguous, keeps two-source closes for them, and switches a misbehaving lookup off for the session after 5 consecutive failures.
