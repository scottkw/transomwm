## Phase Goal

**As a** new user, **I want to** install Transom with Homebrew and be guided through setup, **so that** it starts at login and keeps itself updated.

<objective>
`transom settings [pane]` opens Settings, at a pane if one is named, and `transom help` lists it (SHIP-08, D-04, Phase 8 D-06 "every command reachable from menu, hotkey, URL and CLI").

The tool already turns its arguments into a URL path, checks it with `TransomURL.parse` and sends it (`Sources/transom-cli/main.swift` L30-31); the app parses it again in `CommandGate`. So the CLI only needs an argument branch and a help line.

Purpose: scripts and Terminal users reach a Settings tab the same way as the URL.
Output: the `settings` CLI branch, one CLICopy string, the App help section, and tests.
</objective>
