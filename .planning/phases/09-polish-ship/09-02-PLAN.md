## Phase Goal

**As a** new user, **I want to** install Transom with Homebrew and be guided through setup, **so that** it starts at login and keeps itself updated.

<objective>
`open "transom://settings?pane=updates"` opens Settings on the Updates tab (SHIP-08, D-04).

The route follows the `toggleExcludeFrontmost` precedent: a `Command` case the shell handles. `TransomURL.parse` gains one strict branch for host `settings`, the only place a query is accepted. `ArrangeController` intercepts `.settings` before the Arranger and calls an `openSettings` closure, which `StatusItemController` points at `showSettings(_:from:)` from 09-01.

Purpose: Raycast, Alfred, scripts and the onboarding Done button can open a given Settings tab.
Output: the `.settings` command, the URL branch and its rate-limit rule, and two test files.
</objective>
