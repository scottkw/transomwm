    - remove B from H[A, B] → root is panel A; the split NodeID no longer exists in nodes
    - remove C from V[H[A, B], C] → root is H[A, B] (the inner split takes the root slot, weights unchanged)
    - remove B from H[A 0.5, V[B 0.5, H[C 0.5, D 0.5]] 0.5] → H[A 0.5, C 0.25, D 0.25]
    - remove the only window → empty tree, validate passes
    - remove an unknown window → throws windowNotFound, tree == before
    - tabs [A, B, C] selected 2, remove C → tabs [A, B] selected 1; selected 0, remove A → tabs [B, C] selected 0; tabs [A, B] remove A → panel B with the same NodeID
    - a split whose weights would fall below minWeight after renormalising is clamped: every weight >= 0.01 and the sum is 1 within 1e-9
  </behavior>
  <action>
Write the failing tests in TreeEditTests.swift (`@Suite struct TreeEditTests`) from `<behavior>`. Build the starting trees with `insertRoot`/`insert` or the validating `LayoutTree(root:nodes:states:)`. Then implement.

`remove(_:)` per D-05: on a working copy, find the leaf with `leaf(containing:)` (throw `.windowNotFound` if absent) and delete the window's `states` entry. Panel leaf: delete the node. If it was the root, the tree becomes empty. Otherwise drop the child and its weight from the parent split and divide the remaining weights by their sum (proportional redistribution). Tabs leaf: drop the window from `windows`. If the removed index is below `selected`, decrement `selected`. If it equals `selected`, keep the same index clamped to the new last index. If only one window remains, replace the node with `.panel(thatWindow)` under the same NodeID. Then call `normalize()`, commit and `assertValid()`.

`normalize()` per D-06, as a loop that repeats until a full pass changes nothing: (1) a split with exactly one child is replaced by that child in its parent slot (keeping the slot's weight) or as root, and its NodeID is deleted; (2) a child split whose axis equals its parent split's axis is spliced into the parent at its position, with each grandchild weight multiplied by the child's slot weight, and the child NodeID is deleted; (3) every split's weights are renormalised to sum 1 and then clamped. Clamp: weights below `minWeight` are set to minWeight, and the remaining 1 − (count × minWeight) is shared among the others in proportion to their current weights. Repeat until no weight is below minWeight. maxChildren × minWeight = 1, so this always terminates. normalize() must use an explicit worklist, not recursion. Make `insert` call normalize() on its working copy too (a no-op for its current rules, but it keeps the "normalise after every edit" rule in one place).

Do not change the public signatures from Plan 01.

`resizeBoundary(in:after:by:)` per D-07, on a working copy. The node must exist (`.nodeNotFound`) and be a split (`.notASplit`). `index` must satisfy 0 <= index < children.count − 1 (`.invalidBoundary(split:index:)`). `delta` must be finite (`.invalidGeometry("delta must be finite")`). Let total = w[index] + w[index+1]. Set w[index] = min(max(w[index] + delta, minWeight), total − minWeight) and w[index+1] = total − w[index]. Touch no other weight. Commit and `assertValid()`. Do not call the clamp step of normalize() on the other weights, so they stay bit-identical.

Add the example tests from `<behavior>` to TreeEditTests.swift. Create TreeFuzzTests.swift (`@Suite struct TreeFuzzTests`) with a `fileprivate struct SplitMix64: RandomNumberGenerator`.
