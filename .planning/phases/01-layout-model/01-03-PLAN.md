  <action>
Write the ResolveTests (`@Suite struct ResolveTests`) from `<behavior>` first, then complete `resolve` without changing its signature.

1. Validate input (D-08, threat T-01-06): `area.isValidGeometry` else `.invalidGeometry("area")`; gap finite, >= 0 and <= Geometry.maxCoordinate else `.invalidGap`; every entry in `mins` finite, >= 0 and <= maxCoordinate else `.invalidMinimum(ref)`. Entries for windows not in the tree are allowed and ignored.

2. Snap the area inward and round the gap as in Plan 01, then inset by the gap (D-12). A negative inner width or height counts as zero.

3. Active set (D-17): windows whose `tree.state(of:)` is `.present`. Absent and fullscreen windows are excluded entirely. They get no rect and are not unfit, so their neighbours fill in and the tree is untouched. A leaf takes part if it has at least one active window. A split takes part if at least one child does. Inside a split, the taking-part children keep their stored weights, renormalised among themselves for this resolve only.

4. Effective minimum per active window: (max(1, ceil(min.width)), max(1, ceil(min.height))), with (1, 1) when `mins` has no entry. Aggregate minimum per node: a leaf takes the max width and max height over its active windows (tabs share one rect). A horizontal split's width is the sum of its children's widths plus gap × (k−1), and its height is the max of their heights. A vertical split is the mirror image.

5. Unfit selection (D-11): while the root's aggregate minimum exceeds the inner size, pick a victim among active windows. If only width is violated, pick the largest effective min width. If only height, the largest min height. If both, the largest min area. Ties go to the larger leaf NodeID, then the larger WindowIdentity. Move the victim to `unfit`, remove it from the active set and recompute. After the loop, try to re-admit unfit windows one at a time in the order they were removed: keep each one whose re-admission still fits (maximality). This is O(n²) over at most maxNodes leaves.

6. Layout: recurse from the root over taking-part nodes with the inner rect. A leaf sets `nodeRects[leaf]` and `windowRects[w]` for each active window in it. A split sets `nodeRects[split]`, then water-fills along its axis. Available length L = length − gap × (k−1). Each child starts unpinned. Repeat: free = L − sum of pinned minimums; share_i = free × w_i / (sum of unpinned weights); pin every child whose share is below its aggregate minimum (pinned share = minimum); stop when nothing new is pinned (at most k passes). Integer lengths: child i < k−1 gets floor(share_i), the last child gets L minus the others (D-13). The aggregate check in step 5 guarantees every length is at least its minimum. Every child gets the split's full cross-axis length. Positions advance by length + gap in child order. Use recursion here: validated trees have depth <= 64.

Document at the top of the file that resolve never changes stored weights (minimums adjust geometry, not intent), and that unfit windows are what Phase 4 shows as represented.
