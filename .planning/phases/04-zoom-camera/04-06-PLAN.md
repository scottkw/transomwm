## Phase Goal

**As a** Mac user, **I want to** zoom out to see every window and zoom back in to any of them, **so that** I can find and focus any window fast.

<objective>
Pointer input for the camera through the existing event tap: ⌘⇧-drag rectangle zoom with its rubber band, target preview, Esc cancel and click re-post; pick mode after zooming out; clicks on the stage; title-bar and Desktop double-clicks.

Purpose: ZOOM-03, ZOOM-06, ZOOM-12 and the double-click halves of ZOOM-10/11.

Output: ZoomTapRules (pure, tested like GreenButton), ZoomInput, InputTap state and event kinds, band and ring drawing in PreviewPanel, stage tile clicks.

Design (RESEARCH Pattern 7):
- `ZoomTapState` is published whole from main behind an `OSAllocatedUnfairLock`, exactly like `greenButtons`. The callback lock-copies it, asks `ZoomTapRules.decide`, yields a `TapEvent` with a new kind and returns nil to consume.
- `ZoomTapRules` lives in TransomMac/Input next to `GreenButton` (it takes CoreGraphics event types); its tests go in TransomMacTests, like `GreenButtonHitTests`.
- The tap mask stays mouse-only (T-03-28); Esc comes from temporary KeyboardShortcuts streams.
- 04-03's `.zoomTo(…, focus:)` and `.camera(.frameWindow, focused:)` / `.camera(.frameDesktop)` carry the actions, so every pointer path reuses the engine's targets, toggles and refusals.
</objective>
