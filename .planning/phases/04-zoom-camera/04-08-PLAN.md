## Phase Goal

**As a** Mac user, **I want to** zoom out to see every window and zoom back in to any of them, **so that** I can find and focus any window fast.

<objective>
Make parking safe on every exit path and prove the phase in the VM: home tiles on quit, Restore All goes home first, crash and crash-loop relaunches bring parked windows back, zoom off provably never touches ScreenCaptureKit, and the live 15-window settle run.

Purpose: success criteria 4 and 5, and CONTEXT D's parking safety ("parked windows return on quit, after a crash and via Restore All Windows").

Output: `homeTiles` in Recovery and Arranger, Restore All home-first, a zoom-off guard test, extended live suites.

Design (RESEARCH Pattern 9):
- Today's quit path deliberately skips docked windows ("docked windows stay where they are"). With the camera, a docked window can be parked or zoomed, so `terminationPlan` gains `homeTiles: [WindowIdentity: Rect] = [:]` (defaulted, existing callers compile) computed by the pure `ViewPlanner.plan(view: .home)` for every shown desk.
- Nothing about the camera is persisted, so a crash relaunch starts home and the existing re-attach and rescue bring windows back; this plan adds the tests that prove it for docked parked windows.
</objective>
