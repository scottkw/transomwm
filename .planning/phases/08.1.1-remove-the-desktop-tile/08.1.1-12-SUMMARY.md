## Decisions Made

- **Keep the subject, add a tile.** Asserting "Whole desk" on a lone window would no longer test the fourths. With one docked tile, the host table (ArrangerFourthTests) gives the exact labels the live tests already used, so they kept their expectations.
- **Fourth command for the too-big setup.** "Dock where it is" would need window 1's centre in the right band of a full-screen tile. With a window that is 0.45 of the screen wide, that pushes it off screen. `.secondHalf` docks it beside window 0 without depending on placement.
