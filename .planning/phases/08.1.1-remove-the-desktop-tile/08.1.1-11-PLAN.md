## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Contract, step 1: remove every engine and shell read of a Desktop leaf (`NodeID.desktop`, `isDesktopHidden`) outside TransomModel, while the model's symbols still compile, and pin RESEARCH Open Question 3 with a test.

Purpose: after 08.1.1-09 nothing creates a Desktop node, so these branches are dead code that keeps Focus, saved views and the zoom hover ring aware of a tile that cannot exist. Removing the readers first lets 08.1.1-14 delete the node kind with only model sites left.

Output: Navigator, Arranger, Arranger+Views, Arranger+Placeholders and ZoomInput without Desktop-leaf branches; re-derived and new tests.
</objective>
