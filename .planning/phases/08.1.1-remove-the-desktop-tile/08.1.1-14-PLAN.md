## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Contract, step 2: delete the engine's last Desktop-rect plumbing. Plan types lose `desktopRect`, the planners lose their unread `wanted:` parameter, and the snap, float and move-out signatures name the visible frame (UI-SPEC substitution rule, completed).

Purpose: after 08.1.1-09 every plan's `desktopRect` is nil and the planners never read `wanted:` (08.1.1-06 stopped framing floaters), so both are misleading API. Removing them with the compiler as the checklist leaves 08.1.1-16 only the model's node kind to delete.

Output: smaller `FramePlan`, `ViewPlan`, `Planner.plan`, `ViewPlanner.plan`; renamed labels with docs; tests updated.
</objective>

## Rules for every task in this plan

- Run from the repo root, on the main tree, one executor at a time: every plan of this phase shares one SwiftPM build tree. `TransomModel` and `TransomEngine` must not import AppKit.
- The compiler is the checklist: delete a symbol or rename a label, then fix every site it lists. Never add a `default:` arm to silence an exhaustive switch.
- Compiler-driven residue (narrowed from `files_modified` by design): after 08.1.1-09 to 08.1.1-11 re-derived every test that needed a Desktop rect, the only test reads of a plan's `desktopRect` left are lines that assert it is nil or pass it through an optional. Deleting `FramePlan.desktopRect` turns each such line into a compile error whose fix is to delete that one line. Those lines may sit in ArrangerLifecycleTests, ArrangerNewWindowsTests, ArrangerHoldOptionTests, ArrangerGreenButtonTests, ArrangerResizeTests, ArrangerDragTests, ArrangerFinderTests, ArrangerDisplaySettleTests or ArrangerReflowTests (recount with `grep -rln desktopRect Tests` first). They are not listed in `files_modified` because each is a one-line deletion the compiler points at, with no expectation to re-derive. If a site needs more than deleting the line (an expectation that still depends on a Desktop rect), stop: that is a miss of 08.1.1-09 to 08.1.1-11; fix it as a re-derivation and name it in the SUMMARY.
- Chesterton's Fence: `Arranger.wantedFrames` stays (Float and Dock read it). Only the Planner's unread parameter goes.
- A `swift test --filter` gate must prove at least one test ran and that no target crashed. Keep the full suite green at the end of the plan. Never on this Mac: live tests, `TRANSOM_LIVE=1`, `transom://` opens.
