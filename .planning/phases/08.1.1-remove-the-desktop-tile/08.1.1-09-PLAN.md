## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Flip the default: every new desk starts with no tree (D-01), so no Desktop tile is created any more and docked windows share the whole visible frame. Re-derive every test that built on the default Desktop tile.

Purpose: the one-line product change that delivers ROADMAP success criterion 1. 08.1.1-06 to 08.1.1-08 already changed every behaviour that relied on a Desktop rect, so what breaks here are expectations of where docked windows sit beside a Desktop share, plus test setups that docked beside it (RESEARCH Pitfall 7: a probe of this flip at HEAD failed 374 tests and crashed one target).

Output: `Desk.init`'s default, `DesktopLeafTests` deleted, every test target green with no test relying on a default Desktop tile, and the flip pinned end to end in `ArrangerFloatingTests`.
</objective>
