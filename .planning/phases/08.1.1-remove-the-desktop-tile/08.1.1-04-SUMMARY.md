# Phase 8.1.1 Plan 04: Delete the two Desktop commands from engine, URL and CLI Summary

**Hide/Show Desktop Tile and Frame Desktop no longer exist as `Command`/`CameraCommand` cases. The engine handlers are gone, and `transom://` and the CLI now report both names as unknown commands. The New Windows Float tooltip reads "New windows float until you dock them."**

## Performance

- Duration: about 6 min
- Started and completed: 2026-11-06
- Tasks: 2
- Files modified: 12 (23 insertions, 72 deletions)

## Accomplishments

- Deleted `Command.toggleDesktop`. The compiler then pointed to every site: the Arranger dispatch arm, the availability arm, the private handler, `isDesktopHidden(focused:)`, the `toggle-desktop` URL entry and help row, and `MenuCopy`'s title arm and `desktopToggle(hidden:)`.
- Deleted `CameraCommand.frameDesktop`. That removed the Navigator camera arm, `Refusal.desktopHidden` and its announcement (no other command used it), `isFramingDesktop(displayUUID:)`, the `frame-desktop` URL entry and help row, and `MenuCopy.cameraTitle`'s arm.
- `TransomURL`'s doc comment now says "two parameterless commands".
- `showingDesktop()` and the other `isDesktopHidden` engine paths are still there. They can no longer be reached from a command, and plans 06 to 08 remove them.
