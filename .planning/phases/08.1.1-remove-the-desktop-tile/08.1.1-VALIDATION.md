# Phase 08.1.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Derived from 08.1.1-RESEARCH.md § Validation Architecture.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Swift Testing (Swift 6.4.2) |
| **Config file** | `Package.swift` (TransomModelTests, TransomEngineTests, TransomMacTests, TransomMacIntegrationTests) |
| **Quick run command** | `swift test --filter 'TransomModelTests\.'` or `swift test --filter 'TransomEngineTests\.<Suite>'` (must print a non-zero "Test run with N tests") |
| **Full suite command** | `swift test && scripts/check-no-appkit.sh` (expect four "Test run with" lines; a crashed target prints none) |
| **Estimated runtime** | ~15 seconds warm (full suite); VM suites several minutes |

---

## Sampling Rate

- **After every task commit:** the module- or suite-scoped `swift test --filter` for the files touched (non-zero count)
- **After every plan wave:** `swift test` (all 4 targets report "Test run with") + `scripts/check-no-appkit.sh`
- **Before `/gsd-verify-work`:** full suite green, VM suites on `pane-test-27` and `pane-test`, then host UAT
- **Max feedback latency:** 30 seconds (unit)
