## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Make floating windows plain macOS windows in the engine's placement code (D-05, D-06, D-14): the Planner and ViewPlanner stop framing, sizing and parking them, the floater floors (G-03-11 B) go, and every hidden-Desktop path that only the retired toggle could reach is deleted with its tests.

Purpose: these rules hold whether or not a legacy Desktop leaf is still in a tree, so they change here, unconditionally, while new desks still carry a Desktop tile (RESEARCH Pattern 1). That moves most of the flip's test churn out of 08.1.1-09.

Output: smaller `Planner.plan` and `ViewPlanner.plan`, Arranger without `floaterFloors`, `showParkedDesktops` and the D-31 guards, and the new `ArrangerFloatingTests` (Wave 0) replacing `ArrangerDesktopTests`.
</objective>
