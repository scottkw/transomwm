## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Contract, step 3: before the node kind goes, take every Desktop tile out of the tests that still build one explicitly (`.withDesktop()`, a raw `.desktop(hidden:)` node, `setDesktopHidden`), re-deriving their expectations with docked tiles only, and re-derive FourthTests' Desktop rows for D-04.

Purpose: 08.1.1-09 converted the setups that leaned on the default Desktop tile; the tests here construct one on purpose, so the default flip left them passing on a shape the product can no longer make. Re-deriving them now, while they still compile, keeps the deletion in 08.1.1-14 a compiler-driven sweep with no expectation work.

Output: thirteen test files re-derived or trimmed; no product code changes.
</objective>
