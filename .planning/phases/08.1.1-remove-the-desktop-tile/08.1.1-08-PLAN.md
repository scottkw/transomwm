## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Contract: delete the Desktop node kind and every symbol that only served it, using the compiler as the exhaustive checklist (RESEARCH Pattern 1, last step), and make a schema-4 file that still names a Desktop node fail loudly.

Purpose: after 08.1.1-07 nothing creates a Desktop node, so every remaining branch is dead code that would mislead the next reader and keep the schema lax. Deleting it also tightens the persisted format to exactly what the code can produce.

Output: `Node` without the case, the Desktop-only APIs gone, Navigator/Arranger/ZoomInput without Desktop-leaf branches, plan types and signatures that name the visible frame, the strict schema-4 rejection test, and every test target compiling and green.
</objective>
