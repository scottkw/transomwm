# Phase 08.1.1 Plan 25: Front floater wins the group dwell by real stacking Summary

The group dwell now ranks the floaters under the pointer and the docked window beneath them by the CG window list's front-to-back order, read once at mouse-down with no AX call. UAT 7a passes on real windows of three apps on macOS 27.2 and 15.7, under exactly the focus state that failed on the host.

## What changed

- **Engine input (Task 1):** `PointerEvent` gained `stacking: [WindowIdentity]?`, a defaulted init parameter, so existing call sites are unchanged. A window press copies it into `DragSession.stacking`. A tab press keeps it on `TearPress` and hands it to the torn tab's session.
- **Ranking:** `floatingGroupTarget` uses `drag?.stacking ?? focusOrder`. With stacking, `docked <= floater` hands the drop to the docked tile, so on a tie (both unlisted) the docked window wins. Without stacking, the old `<` rule is unchanged. The `shortcut: focus recency` note is replaced by one line saying stacking decides and focus is the fallback.
- **Shell:** `ArrangeController.handle(_:)` reads `CGWindowList.onScreenFrontToBack()` only when a `.down` hits a tracked window or a tab. It maps the list through the pure `CGWindowList.frontToBack` (layer 0 only, list order, untracked entries and repeats dropped) via `trackedWindow(cgID:)`. If the list is unavailable it passes nil. The list is never logged.
- **Ranking rows (Task 2):** four tests cover a floater behind the docked window (focused later, still no group, and B's centre groups with B), two floaters (the front one wins over the one focused later), a front floating group ("Add as a tab"), and stacking that lists neither window (the docked window wins, and the dragged window, listed first, is never a candidate). Each row fails under the old focus rule.
- **Live 7a (Task 3):** the fixture gained `order-front <i>` (`orderFrontRegardless`, no activation), and `LiveArrange.start` gained a multi-fixture overload. `aFrontFloaterTakesTheGroupDwellOverTheDockedWindowBeneath` launches T, W, then B (so B's app was activated last), docks B, orders T and then W in front, and drags W with ⌥ held onto T's centre.
