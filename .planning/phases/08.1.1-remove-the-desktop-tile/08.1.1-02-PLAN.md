## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Take the two commands that only make sense with a Desktop tile out of every route: Hide/Show Desktop Tile (D-09) and Frame Desktop (D-13), and reword the shell copy that still says "on the Desktop" (UI-SPEC Surface 1 and Copywriting Contract).

Purpose: after this plan no user action can hide a Desktop tile or frame one, so every hidden-Desktop path left in the engine is unreachable and the next plans can delete it with its tests. Doing it before the Dock Window menu (08.1.1-03) keeps the Arrange section and the Shortcuts table changes in two clean steps.

Output: smaller `Command`/`CameraCommand`, URL table, hotkey table, menus and Shortcuts window; ZoomInput without the wallpaper double-click; reworded NoticeCopy and MenuCopy strings; updated tests.
</objective>
