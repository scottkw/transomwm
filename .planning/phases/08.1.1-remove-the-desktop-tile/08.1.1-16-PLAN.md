## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Contract, last step: delete the Desktop node kind and every model symbol that only served it, using the compiler as the exhaustive checklist (RESEARCH Pattern 1, last step), and make a schema-4 file that still names a Desktop node fail loudly.

Purpose: after 08.1.1-13 to 08.1.1-15 nothing outside the model reads a Desktop leaf and no test builds one, so what is left is dead model code that keeps the persisted format lax. Deleting it tightens the format to exactly what the code can produce.

Output: `Node` without the case, the Desktop-only model API gone, the strict schema-4 rejection tests, and every test target compiling and green.
</objective>
