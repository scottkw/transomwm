# Phase 08.1.1 Plan 07: Every command works on an empty desk and uses the visible frame Summary

On an empty desk, New Windows: Tile, Dock Where It Is, Arrange All and Split with New Finder Window now dock the first window as the root. Snap, Float, Float All and the tab-group floats now place windows on the visible frame. The Desktop-showing helpers are gone, so no command can throw `nodeNotFound(n0)`.

## Performance

- **Duration:** about 7 min
- **Completed:** 2026-11-06
- **Tasks:** 3
- **Files modified:** 12

## Accomplishments

- **autoTile:** the drop is the focused docked tile or the largest tile. On an empty tree it is `.emptyLayout`. A tree with no placed tile still returns `[]`.
- **Dock Where It Is:** needed no code change. `Planner.dockTarget` already gives `.emptyLayout`, and a new test pins that.
- **arrangeAll:** the first window becomes the root through `applyDrop(.emptyLayout, leaf:)`. The rest dock beside the largest tile.
- **Finder split:** `FinderExpectation.target` is now `NodeID?`. `finderSplit` targets the focused docked leaf, then the largest tile, then nil. `takeFinderWindow` drops at `.layoutEdge(edge)` when the target is nil.
- **Snap:** passes the visible frame to `Snap.frame`. The Planner `desktopRect` guard is gone, so Maximize fills the screen over docked tiles, and snap works on an empty desk.
- **Float, Float All, Float Group, commitTearOff, dissolve:** no longer show the Desktop. They clamp or centre into `area`.
- **tearOffMiss:** `clampInto: display.visibleFrame`.
- **moveOut:** uses the visible frame for `moveOutFrame`, and beeps when there is no display.
- **Deleted:** `showingDesktop()` and `tearOffDesktop(_:on:)`.
