## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Add the World paths for OS facts that must never land on the undo stack, and meet the Phase 2 obligation that `windowRekeyed` re-points layout references and undo snapshots.

Purpose: SAFE-06 and every tile depend on window identity staying right when a fallback ID is corrected (02-16). Floating windows moved by the user, and windows that lose their room (D-26), are facts, not edits, so they need non-undo paths that still validate the World. Undo (TILE-09) must not throw floating windows back.
Output: `World.rekey`, `UndoHistory.rekey`, `DesktopLayer.rekey`, `World.recordFloatingFrame`, `World.reflow`, the floating-frame rule in `World.undo`, and LifecycleSync's windowRekeyed arm.
</objective>
