## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Give each display and each Space its own layout (D-25), using the Phase 2 Spaces lookup, and keep fullscreen windows' tiles reserved across the fullscreen Space (WIN-07). Fill `Displays.currentSpaceID` and emit `spaceChanged`, both owed by Phase 2.

Purpose: Only the visible Space is arranged, because the tracker keeps windows on other Spaces as present. Without per-Space desks, Pane would move windows it cannot see.
Output: `SkyLightSpaces.currentSpace(displayUUID:)`, `Displays.current()` with Spaces, `spaceChanged` emission, `WindowInfo.spaces`, the Arranger's desk keying and re-home rule, fake Space-per-display support, tests.
</objective>
