## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Persist the layout so that quitting and relaunching Pane while apps keep running brings each display's layout back with the same windows in their tiles (SAFE-06). One validated, atomic file holds the World (with the Desktop tile from 03-01), the home frames and the session record (D-16).

Purpose: SAFE-06, and the store the crash path (plan 13), the park path (plan 08) and quit restore (plan 14) write to.
Output: `LayoutFile`, `LayoutRestore.reattach`, `LayoutStore`, `World.withoutTitleHints()`, the Arranger's `.save` effects and `.restore` input, controller wiring, tests.
</objective>

| T-03-15 | Tampering / Denial of service | LayoutStore.load | high | mitigate | Size cap at World.maxEncodedBytes, version probe first, World's validated decode, finite in-range home frames, unique identities; any doubt rejects the whole file, logs it and moves it aside; tests cover each rejection |
