## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Save the wanted frames from 03-25 in layout.json, with backward-compatible decoding and round-trip tests. This is the last item of the shared G-03-4 / G-03-11 design: "kept while the window is docked, and saved in layout.json". Without it, a relaunch forgets every docked window's pre-dock frame, and Float falls back to the centred frame.

Why a second plan: 03-25 already has three TDD tasks in Arranger.swift and Planner.swift. Persistence crosses into PaneMac (LayoutStore, ArrangeController) and its own test target, so one plan would exceed 3 tasks and touch more than 5 files per task. 03-26 changes Arranger.swift too (restore input, snapshot, reattach), so it runs after 03-25 in wave 2.

Design (smallest complete change):
- LayoutFile:
  - gains `wantedFrames: [HomeFrame]`, sorted by identity like `homeFrames`. The `HomeFrame` record (identity plus frame) is reused, with its doc comment widened.
  - its init takes `wantedFrames: [WindowIdentity: Rect] = [:]`, so existing callers compile.
  - `wantedFrameMap` mirrors `homeFrameMap`.
  - a hand-written `init(from:)` decodes a missing `wantedFrames` key as empty. Encoding stays synthesized.
  - no schema bump: an older Pane ignores the extra key, and a newer Pane reads an older file.
- LayoutStore.decode validates wanted frames exactly as home frames (geometry, duplicates).
- Arranger:
  - `.restore` gains `wantedFrames: [WindowIdentity: Rect] = [:]` (a defaulted associated value, so the 31 existing call sites compile).
  - `pendingRestore`, `unattached` and `snapshot` carry it, so a save while the restore waits keeps the saved wanted frames.
  - `reattach` adopts them by identity, with the two safety rules in must_haves: a floater moved while Pane was not running keeps its real frame; a stranded saved frame is dropped. Then 03-25's seeding fills the floaters still without one.
  - `wakeDormant` applies the moved-while-off rule to a dormant floater it records.
- ArrangeController passes the map into `.restore` and `snapshot.wantedFrames` into every save.

Undo is unchanged: wanted frames are not part of desk snapshots (03-25).
</objective>
