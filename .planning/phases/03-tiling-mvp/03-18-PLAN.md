## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Close UAT gap G-03-4: a plain green-button click must toggle dock/float instead of letting macOS go fullscreen.

Root cause (binding, from 03-UAT.md and .planning/debug/g-03-4-green-button.md): the session tap's window-under-pointer field is 0 for every press (HID and injected), so InputTap falls back to `CGWindowList.topmostWindow(at:)`. That function has no layer filter, so on macOS 15 it returns the Dock's full-screen layer-20 window (CG 7). `GreenButton.shouldSwallow` finds no rect for ID 7, the press passes through, and macOS full-screens the window. `ArrangeController.pressWindow` already filters layer 0, which is why drags work.

Option-click is out of scope: it already passes through and D-33 returns the window to its tile. The user decided on 2026-10-26 to keep D-33, so Option-click behaviour does not change.

Purpose: TILE-06 works for real clicks. The selection becomes a pure, tested function, so the case that slipped through (no gate exercised the tap's window lookup) is covered.
Output: the fixed `CGWindowList.swift`, `TopmostWindowTests.swift`, and a VM re-check of UAT test 4.
</objective>
