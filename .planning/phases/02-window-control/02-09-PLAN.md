## Phase Goal

**As a** Mac user, **I want to** grant Pane access and have it track and move every window, **so that** no slow app or lock screen can freeze or lose them.

<objective>
Make sure Pane never loses a window by mistake: a window counts as closed only when the AX element is invalid (or NSWorkspace says the app quit) and the window is gone from the CG window list; timeouts, hung apps, lock screen and sleep change nothing; and reconciliation pauses during lock and sleep with a full refresh afterwards.

Purpose: WIN-09 and D-09 (ROADMAP SC4 second half), D-06 (minimised = absent), D-14 (lock blanking and id churn scenarios), and WIN-02's "closed later".
Output: CloseRule + ClosedIDCache, close handling in the tracker, cached-element probes, SessionGate, fake scenarios and integration tests.
</objective>

Per D-09, D-06 and D-14. Scenario tests first (RED), then implementation (GREEN).

WindowTracker: assign `creationOrder` from a monotonically increasing counter to every newly reported window. In `ingest`, for every known window of the pid build an AXWindowFact (listed observation with a successful read → `.valid(listed: true, ...)` using snapshot minimized/fullScreen and the app's hidden flag; an unlisted probe that succeeded → `.valid(listed: false, ...)`; `.invalidElement` → invalidElement; `.cannotComplete` → timedOut; anything else → otherFailure; no observation at all for a known window → timedOut) and apply `CloseRule.decide(sessionActive:app: .alive, ax:inCGList:isKnownTabMember: false)`: `.closed` → remove, insert into ClosedIDCache, emit windowDestroyed; `.state(s)` → set and emit windowStateChanged when it differs; `.noChange`/`.recheck` → nothing. A whole-app `listFailure` makes every known window of that pid timedOut. `appTerminated(pid:context:)` marks the pid terminated and decides each of its windows with `app: .terminated`; `recheckTerminated(context:)` re-decides windows of terminated pids against a fresh CG list and forgets a pid once it has no windows. A new identity that ClosedIDCache contains is treated as a brand-new window (fresh creationOrder and classification, normal settle rules). `knownWindowIDs(pid:)` lists tracked ids.

AXAppThread: `observe(known:)` additionally probes, through the thread's element cache, each known id that is not in the current AXWindows list (one AXRole read), returning a WindowObservation with `listedInAXWindows: false`; ids with no cached element are omitted (the tracker treats them as timedOut, never closed).

AXWindowSystem: pass `tracker.knownWindowIDs(pid:)` to `observe(known:)`; on app termination call `tracker.appTerminated` with a fresh CG snapshot, and on every later sweep and refresh call `recheckTerminated`; a kAXUIElementDestroyedNotification only schedules a refresh.

FakeWindowSystem: `close(id)` sets axValid false and inCGList false; `setLocked(true)` makes every observation `listFailure: .cannotComplete`, empties the CG list and builds contexts with `sessionActive: false` (unless a test opts out with `setLocked(true, gate: false)`); `terminate(pid:)` calls the tracker's appTerminated.

CloseIntegrationTests (`.serialized`, `.enabled(if: IntegrationEnv.trusted, ...)`, `@MainActor`, `.timeLimit(.minutes(1))`): fixture `--window standard --window standard`; `send("close 1")` → windowDestroyed for that id within 1 s and the other window kept; `stop()` for 3 s with a `refreshAll()` each second → both remaining windows still tracked, then `resume()`; `send("hide-app")` → .absent, `send("unhide-app")` → .present; `terminate()` → windowDestroyed for every fixture window within 2 s.

SessionGate keeps one Boolean per signal family (screen lock, system sleep, display sleep, session inactive, loginwindow frontmost, CGSession lock flag) and is paused when any is true.
