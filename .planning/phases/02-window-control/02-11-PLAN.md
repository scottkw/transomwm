## Phase Goal

**As a** Mac user, **I want to** grant Pane access and have it track and move every window, **so that** no slow app or lock screen can freeze or lose them.

<objective>
Make the one private API in this phase optional in practice, not just in theory: when `_AXUIElementGetWindow` is missing, forced off or misbehaving, Pane identifies windows by matching them to the CG window list by pid and frame (and title when available), falls back to stable synthetic IDs only when a match is ambiguous, and keeps confirming closes with two sources.

Purpose: SAFE-05 and D-15 (ROADMAP SC5), plus the assumption-delta decision recorded in 02-01-PLAN.md.
Output: FallbackMatcher (+ tests), session-level capability degradation, fallback ID assignment on the app thread, synthetic CG presence, integration tests.
</objective>

Per D-15 and RESEARCH Pattern 8. Tests first (RED), then implementation (GREEN).

FallbackMatcher: candidates are same-pid entries whose bounds match `frame` within `boundsTolerance` on every side and whose id is not in `excluding`. If any candidate is layer 0, drop the others; if exactly one candidate is onscreen, return it; with several, use `cgNames` (non-empty names equal to the observed title) to narrow to one; a single remaining candidate → `.cg`, several → `.ambiguous`, none → `.none`. `syntheticPresence` returns copies of matching CG entries re-labelled with each synthetic identity's windowID, for identities whose `isSyntheticWindowID` is true.

Capabilities: add session state guarded by an `OSAllocatedUnfairLock` (macOS 13+; `Mutex` is macOS 15+ and would break the 14 floor): consecutive failure count and a session-disabled set. `isAvailable(.axWindowID)` is false when forced off, when `AXWindowID.function` is nil, or when session-disabled. `recordFailure` increments and, on reaching `failureLimit`, disables for the session and logs once at `.error` with privacy `.public`; `recordSuccess` resets the count. `report()` now returns `isAvailable` per capability.

Per D-15.

AXSnapshotReader / AXAppThread: when `Capabilities.isAvailable(.axWindowID)` is true and the thread is not forced into fallback, behave as before; record a success after each good lookup and a failure when the lookup fails for an element whose role read as AXWindow and whose batched attributes succeeded (never for -25201 on non-windows). When unavailable: for each AXWindows element already in the thread's element cache reuse its assigned ID and idSource; for a new element call `FallbackMatcher.match(pid:frame:title:cgWindows:cgNames:excluding:)` with one `CGWindowList.snapshot()` per observation (CGWindowList is nonisolated and thread-safe), `excluding` = IDs already bound in this pid's cache; only when the first match is `.ambiguous` fetch `CGWindowList.names(pid:)` and match again; `.cg(id)` → that id with `.cgFrameMatch`; `.ambiguous`/`.none` → `SyntheticWindowIDs.next(avoiding:)` (every CG id in the snapshot) with `.synthetic`. The assignment is stored with the element so it is stable for that element's life.

SyntheticWindowIDs: `0xF000_0000 | counter` from an `OSAllocatedUnfairLock`-guarded counter, skipping values in `avoiding`; a `precondition` on exhausting the 28-bit range (unreachable in a session).

CGWindowList.names(pid:): reads kCGWindowName for that pid's entries (non-empty only with Screen Recording); names are used for the match and dropped; never logged.

AXWindowSystem: add `forceWindowIDFallback: Bool = false` to the initialiser and pass it to each thread; before each `tracker.ingest`, append `FallbackMatcher.syntheticPresence(trackedSyntheticWindows, cgWindows:)` to the context's CG list so synthetic windows close only by AX-invalid plus no same-bounds CG window. `capabilityReport` returns `Capabilities.report()` (now session-aware), which the menu and footer already render.

FallbackIntegrationTests (`.serialized`, `.enabled(if: IntegrationEnv.trusted, ...)`, `@MainActor`, `.timeLimit(.minutes(1))`), with `forceWindowIDFallback: true`: (a) fixture `--window standard --window standard --window tabs:2` → every listed window is tracked; untabbed windows have idSource .cgFrameMatch and windowID equal to the fixture's printed id; the tab group's visible tab matches its onscreen id; (b) fixture with two standard windows moved to identical frames before AXWindowSystem starts → two distinct identities, each idSource .cgFrameMatch or .synthetic, every synthetic ID ≥ 0xF000_0000 and different from every fixture id; closing one (`close 1`) yields exactly one windowDestroyed within 2 s and keeps the other.
