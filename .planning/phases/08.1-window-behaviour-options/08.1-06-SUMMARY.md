# Phase 8.1 Plan 06: New Windows Summary

**With menu ▸ Arrange ▸ New Windows ▸ Tile, a window opened while Transom runs docks beside the focused tile along its longer side as one undo step, while windows that were only just noticed, dialogs, panels, small windows, windows re-matched to a tile and windows that don't fit all float with no beep or notice.**

## Accomplishments

- `WindowInfo.openedWhileRunning` is decided once, at first sight. A window counts if it's above the initial sweep's highest real CG ID, has a real ID, and isn't under a sheet.
- `autoTile` runs after re-matching and before `admit`, so a docking window never shows a hidden Desktop. Every guard that fails returns nothing and the window floats through `admit`.
- The undo step's snapshot holds the window floating at the frame it opened at. With a hidden Desktop it isn't in the snapshot, and undo re-admits it through the existing loop, which shows the Desktop (D-31).
- New Windows sits between Gaps ▸ and Drag to Dock ▸, with no separator. It's saved, applied at once and announced once, and it stays enabled while paused or not ready.

`autoTileMinimum` is 200 x 120 pt. RESEARCH Assumption A4 (CG IDs only rise within a boot) didn't matter in any row: IDs rose in every VM run, and `aLaterWindowBelowTheSweepIsAnOldOneFirstSeenLate` pins the lower-ID case with a constructed observation.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] A window first seen under a sheet docked**
- **Found during:** Task 3, first VM run on macOS 27.2
- **Issue:** The plan says a sheet at first sight needs no code, but its own gate requires `open sheet` to stay off the tree. The fixture's host window docked and added an undo step. The Classifier returns a provisional `.dockable` for a window under a sheet, so `autoTile` couldn't tell it from a judged window.
- **Fix:** The tracker doesn't count a window whose snapshot has `sheetAttached == true`. It floats, the safe direction, and stays that way, so a real document window opened with a sheet already attached also floats until the user docks it.
- **Files modified:** `Sources/TransomEngine/WindowTracker.swift`, `Sources/TransomEngine/WindowSystem.swift`, `Tests/TransomEngineTests/WindowTrackerTests.swift`
- **Verification:** `aWindowFirstSeenUnderASheetIsNotCounted`, and `aPanelAndASheetStayFloatingInTileMode` on both OSes
