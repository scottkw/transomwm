## Phase Goal

**As a** multi-display user, **I want to** see every window on every display and Space in one overview, **so that** I can jump anywhere and keep each layout.

<objective>
The shell half of OVER-05/OVER-06: debounce display reconfiguration (D-11), hold it while the session sleeps or is locked, deliver the Engine's settling inputs, save layout sets, and show the user-visible bits (N12, Debug S2-S4).

Purpose: the Engine rules from 06-04 only work if the shell starts settling at the earliest signal and never acts while asleep. Hot-plug can't be tested in the Tart VM, so the timer logic is unit-tested with an injected clock and the real behaviour goes to the 06-12 hardware checklist.

Output: `DisplaySettler`, its wiring through AXWindowSystem and ArrangeController, N12 copy and merge, Debug S2-S4.
</objective>
