## Phase Goal

**As a** multi-display user, **I want to** see every window on every display and Space in one overview, **so that** I can jump anywhere and keep each layout.

<objective>
The Mission Control takeover engine (OVER-02, OVER-03, D-05, D-07, D-08): a pure, fully tested policy for when to store, disable, restore and re-apply; the shell controller that executes it against SymbolicHotKeys with crash-safe ordering; the launch restore; and the Mission Control keys opening the overview.

Purpose: disabling a symbolic hotkey is WindowServer session state that outlives the process (06-SPIKE "Abort persistence"). A wrong order or an overwritten original loses the user's Mission Control for the rest of the login. This plan keeps that state machine headless-testable and proves the real path in the VM.

Output: `TakeoverPolicy` + `TakeoverKeys` (Engine), `MissionControlCanary` (TransomPrivate, a copy of MultitouchCanary per D-07), `MissionControlTakeover` (TransomMac), launch and quit wiring, a VM live test. The menu toggle, alert, notices and Debug line are 06-11.
</objective>
