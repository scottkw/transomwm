## Phase Goal

**As a** multi-display user, **I want to** see every window on every display and Space in one overview, **so that** I can jump anywhere and keep each layout.

<objective>
The Engine half of OVER-05 and OVER-06: a display "settling" state that stops re-homing from destroying the layout a re-plug needs, and per-arrangement layout sets switched automatically.

Purpose: today `.displaysChanged` is a no-op and `rehome` floats any window macOS moves off a vanishing display, so nothing remembers its tile (RESEARCH "Problem in today's code"). This is the research's second must-fix regression.

Output: Arranger inputs and state, the pure switch/merge rule in `Arrangements.swift`, N12 as a `Notice` case, a FakeWindowSystem model of unplug (Spaces moving to the remaining display, A6), and scenario tests. The shell (debounce, SessionGate, save) is 06-05.
</objective>
