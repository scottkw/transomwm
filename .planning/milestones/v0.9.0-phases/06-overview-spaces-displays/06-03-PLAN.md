## Phase Goal

**As a** multi-display user, **I want to** see every window on every display and Space in one overview, **so that** I can jump anywhere and keep each layout.

<assumption_delta_decision>
The detector fired (pluralization): a Space's identity gains a second form (the persistent UUID beside the runtime numeric ID), and the single saved World gains siblings (one per display arrangement).
- Space identity. Primary noun for persistence: the macOS Space UUID. Decision: add-alongside. `DeskKey(displayUUID, spaceID: UInt64?)` stays the runtime key (World Codable, validation and every Arranger lookup depend on it); the UUID lives in the LayoutFile `spaces` side table and is applied by SpaceRekey at load. Accepted debt: a later promote (UUID inside DeskKey) would be forced if numeric IDs prove unstable within one login session, or if Phase 8's reboot restore needs desks addressable by UUID before Spaces are enumerated.
- Saved layouts. Primary noun: the display arrangement (`ArrangementID`). Decision: add-alongside. `LayoutFile.world` stays the current arrangement's World (the Arranger is unchanged); other arrangements live in `layoutSets`. Invariant test (06-04): every stored LayoutSet round-trips through switch → reattach for every arrangement it was saved under.
</assumption_delta_decision>

<objective>
LayoutFile schema 2 (the user's 06-01 "Schema decision"), the Space-UUID table with re-keying on load (D-13), and the arrangement value types the next plan's switching rules use (D-09, OVER-06).

Purpose: per-Space layouts are already correct at runtime, but layout.json stores numeric Space IDs only. Without the UUID table a relaunch can file a desk under the wrong Space, and without accepting schema 1 every user's layout is set aside on upgrade.

Output: `LayoutFile` v2 with migration, `SpaceRekey`, `Arrangements` types, the LayoutStore version gate, and the restore/save path in ArrangeController.

If 06-SPIKE.md "Schema decision" says "additive-v1" instead, keep `schemaVersion = 1`, decode the three new keys with `decodeIfPresent` defaults (like `wantedFrames`), drop the version-1 branch work, and keep every other behaviour and test in this plan.
</objective>
