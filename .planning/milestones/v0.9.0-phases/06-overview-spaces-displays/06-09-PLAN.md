## Phase Goal

**As a** multi-display user, **I want to** see every window on every display and Space in one overview, **so that** I can jump anywhere and keep each layout.

Purpose: the overview must never strand the user (stuck panels, keys still taken) or move windows they didn't pick, and it must be usable with VoiceOver and Reduce Motion.

Output: the remaining OverviewController behaviour, copy and Debug line, a gesture-disarm reason, extended VM live tests.
</objective>
