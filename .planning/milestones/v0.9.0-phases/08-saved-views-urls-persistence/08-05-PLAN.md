## Phase Goal

**As a** power user, **I want to** save views to hotkeys and run Transom from transom:// URLs, **so that** my layouts and automations survive restarts.

<objective>
The CLI tracer: `transom view 3` parses, is checked with the shared `TransomURL` parser, crosses a CFMessagePort to the running app, passes the shared allow-list and rate limit, runs the same command as ⌥3, and exits 0 with nothing printed. Then the exact CLI copy and every exit code, the two view URLs and their rejected forms, and finally the bundle embedding at `Contents/Helpers/transom`.

Purpose: VIEW-03 (view URLs) and VIEW-05 (bundled CLI with non-zero exits). The VM check of the installed bundle and the README come in 08-07.

</objective>
