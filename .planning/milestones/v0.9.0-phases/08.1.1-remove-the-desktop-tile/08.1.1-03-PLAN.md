## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Take Hide/Show Desktop Tile (D-09) and Frame Desktop (D-13) out of the AppKit shell: the menu bar menu, the hotkey table, the Shortcuts window and the wallpaper double-click; and reword the toasts that still say "on the Desktop" (UI-SPEC Surface 1 and Copywriting Contract).

Purpose: after this plan no click, chord or double-click a user makes can reach either command; 08.1.1-04 then deletes the commands from the engine, URL and CLI with only those routes left. Doing the shell before the Dock Window menu (08.1.1-05) keeps the Arrange section and the Shortcuts table changes in two clean steps.

Output: smaller hotkey table, menus and Shortcuts window; ZoomInput without the wallpaper double-click; reworded NoticeCopy; updated Mac tests.
</objective>
