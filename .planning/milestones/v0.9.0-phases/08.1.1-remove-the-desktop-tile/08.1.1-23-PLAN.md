## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Add corner quarters as docking positions (8.1.1 D-17): Top Left, Top Right, Bottom Left and Bottom Right, each exactly that quarter of the visible frame (D-16), in the model and engine, by URL and by CLI. 08.1.1-24 adds the hotkeys, the menu section and the Shortcuts rows.

A corner is two halves at once, a row half and a column half, so it needs the empty areas from 08.1.1-20 and the share function from 08.1.1-21.

Purpose: the user's UAT issue 3 ("the Dock Window menu has no corner quarters").
Output: `DockCorner`, `LayoutTree.insertCorner`, `DropTarget.corner`, `Command.dockCorner`, quarter labels, four URL and CLI commands with help lines.
</objective>
