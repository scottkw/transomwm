# Phase 08.1.1 Plan 06: Floating windows are plain macOS windows in the engine Summary

Planner, ViewPlanner and Arranger no longer frame, clamp, size for, park or raise a floating window. Floater floors, the hidden-Desktop parks, the D-31 Desktop-show guards and `showParkedDesktops` are gone. Lost-room floats now clamp into the visible frame in one pass.

## What changed

- **Planner.plan** (Task 1, 199b035): resolves the tree once with the default Desktop minimum. `frames` is `resolution.windowRects`. `parks` holds hidden tabs and floating groups' hidden members (at `TabBand.content(of: group.frame)`). The floater sizing, drop/add-back loop (G-03-6, WR-02), hidden-Desktop parks, floater framing loop and the `floors:` parameter are deleted. `wanted:` stays unread until 08.1.1-14 deletes it.
- **Arranger floater bookkeeping** (Task 1): `floaterFloors` is removed along with every use: rekey, `.frameApplied` floor learning, close, `moved` and `boundaryChange`. `moved`'s floating branch no longer clamps; it records the frame and replans.
- **ViewPlanner** (Task 2, 2550be3): a node view's desk is `Desk(tree: subtree, desktop: desk.desktop)`. `outside` is docked windows only, and `showsDesktop` is gone. Zoom off while paused rescues every stranded window, with no hidden-Desktop set spared.
- **widen(toShow:)** (Task 2): the plan asked whether `widen` skipped floaters only because views parked them. It did not skip them: `leafNode(of:)` returns `.desktop` for a floater on a shown Desktop, so a new floater widened the camera to the Desktop. It now uses `tree.leaf(containing:)`, so a floater never moves the camera. This matches the plan's "the camera does not widen for it".
- **Hidden-Desktop paths** (Task 3, e0499f6): `showParkedDesktops` and its two callers are removed. Restore All keeps the loop that records each rescued floater's frame, now inline. The `isDesktopHidden` conditions are gone from `wakeDormant`, `movedWhileOff`, `moved`, `admit`, `rehome` (D-31), `canDrag` and `planShown`.
- **planFloatingLostRoom** is now one pass. Each lost window floats at `Planner.clamp(frame, into: area)`. **cascadeFloated** starts at the visible frame's top-left.
