# Phase 08.1.1 Plan 20: Empty-area leaf and layout.json schema 5 Summary

**Checkpoint answer (Task 1, D-20): option-a, an invisible empty-area leaf saved in layout.json schema 5. Rules E1–E7 accepted as written, with no changes.**

**The layout tree can now hold empty parts of the screen. `Node.spacer` takes its share of a split with a zero minimum and gets a node rect but no window rect. So [W .5 | empty .5] keeps W at exactly the left half, the same rect W gets in [W .5 | X .5]. Hostile shapes are rejected on load: an empty root, adjacent empty areas, or a split with no window. Edits keep empty areas in normal form. A leaving window gives its space to an empty area beside it (E5). `vacate` leaves an empty area behind (E4), and `fill` puts a window or tab group into one (E6). layout.json is schema 5: schema-4 files load unchanged, are backed up, and save as schema 5. No command creates an empty area yet.**

## Accomplishments

- `Node.spacer` (JSON key `spacer`). validate rejects a spacer root and adjacent spacers, with `invariantViolated` naming NodeIDs only. That also rejects every split with no window. `windows`, `leaf(containing:)`, `World.refreshingTitles` and `rekey` skip it.
- resolve: an empty area always takes part with a zero minimum and is never unfit. When every window is absent, it gets the whole inner rect and nothing is drawn. A guard skips placement when empty-area gaps alone overflow a tiny area. `Fourths.takesPart(.spacer)` is true.
- Engine `switch`es get `.spacer` arms without a `default:`: focus neighbour, floatAll, groupable, `ViewPlanner.subtree(at:)`.
- layout.json schema 5. `case 2, 3, 4, LayoutFile.schemaVersion` decodes. The Desktop home-frame bring-back and the D-15 migration line are gated on `version <= 3`. A backup is written for any older schema. `World.currentSchemaVersion` stays 2, and a doc comment explains why.
- TreeEdits: `normalize()` merges adjacent spacers, and a spacer root empties the tree. `removeLeaf` applies E5. Added `vacate(_:)` and `fill(_:with:states:)`. `group` into a spacer throws `notALeaf`. One `members(of:)` helper now serves removeLeaf, vacate and checkNewLeaf.

- **Commit:** 0e378c0, fd8be2f

- **Commit:** fd8be2f
