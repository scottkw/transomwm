## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Migrate every saved layout off the Desktop tile (D-02, D-03, D-15) while the rest of the code still compiles with it, so no user loses a layout when the node kind is deleted later (RESEARCH Pitfall 1), and bring back windows a hidden Desktop tile had parked (Pitfall 2). Also record the phase's requirement amendments.

Purpose: this is the phase's riskiest door: layout.json is a one-way format. Doing it first proves the decode → validate → drop → save path end to end on a real schema-3 file before any behaviour changes.

Output: `LegacyNode` and the legacy-tree migration in TransomModel, World schema 2, layout.json schema 4, LayoutStore's version switch and log line, the restore bring-back, the V3 fixture, `DesktopMigrationTests`, and the REQUIREMENTS/ROADMAP edits.
</objective>
