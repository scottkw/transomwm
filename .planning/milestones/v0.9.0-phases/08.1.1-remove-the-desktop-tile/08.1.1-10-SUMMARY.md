## Decisions Made

- **Stand-ins instead of deletions.** Many tests used the Desktop tile only as "a sibling that is not the subject". A docked window now plays that role, so the subject and most numbers survive: resize row and corner, saved-view node, fourth group cases, learned-minimum anchors. This is the D-01 world: what used to be beside the Desktop is now beside another docked window.
- **Deleted `ArrangerViewsTests.savingAViewWithNoWindowsIsRefusedAndKeepsTheSlot`.** It zoomed to `.node(.desktop)` to find a node with no windows. With no Desktop node, every node holds at least one window (`tree.windows` includes absent ones), so `Arranger+Views.swift`'s `viewNothingToSave` refusal cannot be reached from a node view any more. 08.1.1-16 may retire that guard along with the `showsDesktop` clause beside it. The floating-only saved-view case stays with 08.1.1-13, as planned.
- `case .desktop` arms in the test helpers' exhaustive switches (ArrangerCommandTests `shape`) stay until 08.1.1-16, as the plan rules say.
- `ArrangerCommandTests.arranger(empty:)` and `ArrangerFocusTests.columns(floating:)` are now redundant parameters. Both were left alone: they're harmless, and removing them is outside this plan's scope.
