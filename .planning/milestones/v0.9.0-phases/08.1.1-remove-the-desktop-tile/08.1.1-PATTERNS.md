### Persistence migration (World v1 → v2, LayoutFile 3 → 4)

**Analog 1: the version switch in `Sources/TransomMac/LayoutStore.swift` lines 114-140**
```swift
guard version <= LayoutFile.schemaVersion else { throw .newerVersion(version) }
var contents: LayoutFile
do {
    switch version {
    // Every user's file at the upgrade: migrated in memory, saved as the current schema (RESEARCH Pitfall 1).
    case 1: contents = try decoder.decode(LayoutFileV1.self, from: data).migrated()
    // Schema 2 has schema 3's shape with empty titles; the next save writes schema 3.
    case 2, LayoutFile.schemaVersion:
        contents = try decoder.decode(LayoutFile.self, from: data)
        contents.schemaVersion = LayoutFile.schemaVersion
    default: throw LayoutStoreError.corrupt("unknown schemaVersion \(version)")
    }
} catch let error as LayoutStoreError { throw error } catch { throw .corrupt(String(describing: error)) }
```
For schema 4, change the arm to `case 2, 3, LayoutFile.schemaVersion:`. The Desktop drop happens inside `World.init(from:)`, so it covers `world` and each `layoutSets[].world`. Put the UI-SPEC migration log line next to the existing `Self.logger` calls (lines 48-53), using the same `privacy: .public` style.

## Shared Patterns

### One undo step per user edit
**Source:** `world.edit(key, history: &history) { desk, ids throws(LayoutError) in … }` (as in the helper above).
**Apply to:** halves/thirds docking (already on the `dockFourth` path), the empty-desk `autoTile`/`arrangeAll` root insert. The restore bring-back is an OS fact: use `recordFloatingFrame` with no history (RESEARCH sketch).

### Exhaustive `switch` as the checklist
`FourthSlot`, `Command` and `Node` switches have no `default`. Adding slots and deleting `.desktop`/`.toggleDesktop`/`.frameDesktop` makes the compiler list every site. Do not add `default:` arms to silence it.

### Persistent-name contract
Hotkey raw names and URL command names are user-visible contracts. Add new ones and never rename existing ones. Retired names (`toggleDesktop`, `frameDesktop`, `toggle-desktop`, `frame-desktop`) are not reused.

### Logging
`os.Logger(subsystem: "com.eightabyte.transom", category: …)`, with values interpolated using `privacy: .public` (LayoutStore.swift:50-53, Hotkeys.swift:198).

### Recovery of stranded windows
Copy `rescueStranded` / `showParkedDesktops(keeping:)` (Arranger.swift:846-875) for the restore bring-back: `Recovery.isStranded` + `Recovery.destination(for:home:display:)`.
