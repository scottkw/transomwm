## Decisions Made

- **Own-tile centre, not another tile, for the "no region" spot.** Every spot on a full screen is over some docked tile. The dragged window's own tile is the only one where ⌘ has no swap target and Automatically has no region. That is what the Desktop centre gave the old precedence table. All 36 table rows pass with their original outcomes, so the table's rules are unchanged.
- **Bottom edge band under b, not the right band.** b's right band would re-dock b where it already is, which tests nothing. The bottom band is a real `.layoutEdge(.bottom)` dock. It is over no panel but b's, so ⌘'s "no swap target" rows keep their meaning.
- **Focus beeps.** UI-SPEC Surface 2 makes floating windows never a Focus target. The floating-group focus test therefore now asserts the beep rather than a hidden-vs-selected pick.
- **Minimums sized past the learner's margin.** Several room tests used to get a refusal from the narrow tile beside the Desktop. With halves of 708 pt, the minimums were raised so that each refusal exceeds `MinimumSizeLearner.refusalMargin` (32 pt). An overflow within the margin is never learned (documented learner behaviour, not a defect).
