## Phase Goal

**As a** user, **I want to** have docked windows fill the whole screen and floating windows sit on top of them like normal macOS windows, **so that** I never have to learn or manage a "Desktop tile".

<objective>
Flip the default: every new desk starts with no tree (D-01), so no Desktop tile is created any more and docked windows share the whole visible frame. Pin the flip end to end and re-derive the model target. This is the first of three flip plans (08.1.1-09 to 08.1.1-11); it is the only one that changes product code.

Purpose: the one-line product change that delivers ROADMAP success criterion 1. 08.1.1-06 to 08.1.1-08 already changed every behaviour that relied on a Desktop rect, so what breaks here are expectations of where docked windows sit beside a Desktop share, plus test setups that docked beside it (RESEARCH Pitfall 7: a probe of this flip at HEAD failed 374 tests and crashed one target). The engine re-derivation is split across 08.1.1-10 (batch A) and 08.1.1-11 (batch B) to keep each executor's context sane (user decision 2026-11-06).

Output: `Desk.init`'s default, `DesktopLeafTests` deleted, the model target green, the flip pinned in `ArrangerFloatingTests`, and every suite outside SKIP_A and SKIP_B green.
</objective>
