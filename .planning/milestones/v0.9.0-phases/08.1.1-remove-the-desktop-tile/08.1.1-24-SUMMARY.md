- `Hotkeys.swift`: four new `KeyboardShortcuts.Name`s with persistent raw values `dockTopLeft`, `dockTopRight`, `dockBottomLeft`, `dockBottomRight`; four `entries` rows mapping to `.dockCorner(...)`. `fourthNames` now matches `.dockFourth` and `.dockCorner` (24 names), so `logSystemConflicts` checks the corner chords at launch. `zoomNames` is unchanged, so the corners stay enabled with zoom off.
- `MenuCopy.cornersHeader = "Corners"`.
- `CommandMenu`: a `corners` list (`DockCorner.allCases`) in `commands`; the Dock Window submenu groups are Where It Is, Halves, Corners, Thirds, Fourths (25 items, 4 headers, 4 separators). Headers come from the existing `submenu(_:groups:)`, which uses `NSMenuItem.sectionHeader` (D-19).
- `ShortcutsModel.sections`: the Dock Window section has 25 rows in menu order. Restore Defaults covers the corners through the existing loop over `entries`.
- The ⌃⌥⌘U/I/J/K floating-window snaps are untouched.
