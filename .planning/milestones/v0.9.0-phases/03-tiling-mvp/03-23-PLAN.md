## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Close UAT gap G-03-8 (SAFE-06, Phase 3 SC4). Docked windows on every Space must come back to their own layouts after Pane quits and relaunches while the apps keep running.

Root cause (binding, from 03-UAT.md and .planning/debug/g-03-8-hidden-space-relaunch.md): two facts combine. At launch, AX `kAXWindowsAttribute` lists only the windows of the Space being shown, so a fresh `WindowTracker` never tracks a window on a hidden Space. `Arranger.process(.inventory)` runs `LayoutRestore.reattach` once, at the first complete inventory, and `reattach` closes every saved window that is not tracked. So every saved window on a Space not shown at launch is deleted. Those windows are still alive: the CGWindowList `optionAll` still has each one at layer 0, with the same windowID and pid. The test missed this because its relaunch reused the first session's FakeWindowSystem, and that fake's tracker still knew the hidden windows.

Fix (smallest complete change, existing structure kept):
1. Both window systems report the layer-0 CG windows. `reattach` keeps a saved window as dormant in its desk while a live entry has the same windowID and pid. An app relaunch (new pid) still removes it, because re-matching belongs to VIEW-04 in Phase 8.
2. A dormant window is re-attached on its first `windowCreated`. Its real state is applied, and `lastRequested` is seeded with its real frame, so only a changed tile is written. The planner never writes untracked windows, so the Space-switch plan is not lost to "window not tracked".
3. A dormant window is pruned when its ID leaves the CG list or its app terminates. This was decided so that layout.json does not keep dead windows forever.
4. A headless test on a fresh fake fails today. ArrangerMultiDeskRestoreTests relaunches on a fresh fake.

The clean-exit and crash-recovery launches both go through the same `reattach`, and both are tested. The plan ends with a Claude-driven VM re-check of UAT 17's Space half.

Output: engine, fake and shell changes, tests, and SUMMARY evidence from the VM.
</objective>
