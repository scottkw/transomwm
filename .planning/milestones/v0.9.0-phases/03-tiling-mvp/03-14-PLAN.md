## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Make Pane crash-safe: after a crash or force-quit, the next launch brings stranded windows back on-screen and restores the layout (SAFE-02); a crash loop starts paused (D-18); and "Restore All Windows" brings every window on-screen on demand (SAFE-03; the `pane://restore` URL is plan 15).

Purpose: parked windows (plan 08) and off-screen windows must never be lost, whatever happens to Pane.
Output: `Recovery`, the launch-mode flow, the crashLoop pause reason, `Command.restoreAll`, notices N2/N3/N6, the 33rd hotkey, tests.
</objective>
