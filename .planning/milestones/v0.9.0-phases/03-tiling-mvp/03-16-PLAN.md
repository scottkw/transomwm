## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Detect the macOS features that fight Pane (Stage Manager, macOS edge tiling, click wallpaper to reveal desktop), explain the conflict, offer to turn each off, verify that it took, and restore the originals on request (SAFE-04).

Purpose: success criterion 4's conflict half. Stage Manager moves windows by itself, so arranging pauses while it is on (D-22).
Output: ConflictPolicy, PreferencesStore, ConflictController, conflict menu lines, Restore macOS Window Settings, alerts, N7/N8, tests.
</objective>
