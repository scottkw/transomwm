## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Implement the remaining window commands (park, focus, raise) in both window systems, then use them: hide and show the Desktop tile (TILE-15) and move focus to the neighbouring tile from the keyboard (TILE-09's "focus neighbour").

Purpose: Phase 2 left park, focus, raise and setHidden logged and dropped. Hiding the Desktop is the first feature that parks windows, so the "save immediately before any window is parked" rule (D-16) lands here with it.
Output: perform arms in AXWindowSystem and FakeWindowSystem, thread jobs for focus/raise, the fixture's `frontmost` report, the Arranger's toggleDesktop, home frames, MRU focus and focus commands, five hotkeys, tests.
</objective>
