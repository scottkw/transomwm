## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Split the current tile with a new Finder window by hotkey (TILE-17; the `pane://split-finder` URL comes in plan 15). Pane presses Finder's own New Finder Window menu item through Accessibility, then docks the window that appears.

Purpose: TILE-17 with no Apple Events entitlement and no Automation prompt.
Output: `MenuPress`, the fixture's ⌘N menu, `Command.finderSplit`, the Arranger's Finder expectation, `.openFinderWindow`, N9, the `finderSplit` hotkey, tests.
</objective>
