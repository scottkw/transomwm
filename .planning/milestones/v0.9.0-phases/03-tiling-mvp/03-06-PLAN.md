## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Keep the layout correct as windows change on their own: Pane tells its own writes from app and user moves, puts docked windows back when their app moves them, records floating windows where the user leaves them, and floats a docked window that no longer fits its tile, with a notice (D-26). This plan also adds the toast surface every later notice uses.

Purpose: TILE-03 ("stay correctly arranged as windows open, close and resize") and TILE-07's floating-window facts. Without the echo rule, every frame Pane writes would come back as a move to undo.
Output: echo and app-move handling and lost-room floating in the Arranger, `Notice`, `NoticeQueue`, `NoticeCopy` (N1), the toast panel, the Arranger wake-up, fake user/app move helpers, tests.
</objective>
