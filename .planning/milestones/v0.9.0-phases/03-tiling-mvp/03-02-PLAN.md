## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Add the pure layout edits and geometry the commands need: swap, balance, rotate, flip, grow/shrink a tile, a resize between two named children, the neighbour and boundary lookups, and the snap targets for floating windows.

Purpose: TILE-11..14 and the gap-drag model step of TILE-05. Plans 08, 10, 11 and 12 call these from the Arranger. Every edit uses the existing copy-then-commit pattern, so each command is one `World.edit` and one undo step.
Output: new edits in TreeEdits.swift, Neighbours.swift, Snap.swift, and their tests.
</objective>

All edits follow the copy-then-commit pattern (`var next = self`, change, `normalize()`, `try next.validate()`, then `self = next`) with typed throws and the existing error cases. swap exchanges the windows of two `.panel` leaves; the NodeIDs and states stay where they are, so only the windows move.     - boundary(for: b, edge: .left) in H[a, b] is (split, 0); boundary(for: a, edge: .left) is nil (outer edge); in H[a, V[b, c]] boundary(for: c, edge: .left) is (root, 0) and boundary(for: c, edge: .top) is (the V split, 0)
  </behavior>
  <action>
Per D-11, D-07 and TILE-13. First commit the new LayoutEditTests rows and NeighbourTests (RED), then implement (GREEN).

resizeChild: the delta is a fraction of the split's length. Take it from (or give it to) the other children in proportion to their weights, clamping each at minWeight and redistributing the remainder, then normalize. Throw atSizeLimit when the clamped result equals the input. resizeBetween moves weight only between the two named indices (they need not be adjacent), clamped at minWeight on both sides. Add `atSizeLimit(NodeID)` to LayoutError in LayoutTree.swift, with a doc comment that names NodeIDs only.

Neighbours.swift (new, pure): neighbour considers every non-split node in `resolution.nodeRects`, the Desktop tile included, except `excluding`. For `.right` a candidate's minX must be ≥ rect.maxX − (gap + 1), with positive vertical overlap; mirror for the other edges. The smallest edge distance wins; ties go to the earliest index in `recency`, then the smaller NodeID. boundary walks up from the leaf to the first ancestor split whose axis lays children along the edge's direction (left/right: `.horizontal`) and where the child on the path has a sibling on that side; it returns that split and the index of the boundary.
  </action>
