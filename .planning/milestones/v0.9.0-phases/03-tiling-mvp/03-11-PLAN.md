## Phase Goal

**As a** Mac user, **I want to** drag windows into nested tiles that reflow as windows open and close, **so that** my windows never overlap.

<objective>
Drag to dock (TILE-01): watch the pointer with one active event tap, recognise a title-bar drag from the window's own frame changing while the button is down, show the exact landing frame after 150 ms of hover, and dock there on release. Add the ⇧ bypass (TILE-02), the ⌘ swap (TILE-11), the miss rules, the blocked preview for drops without room, and the tap watchdog.

Purpose: the Core Value: windows dock into nested tiles by dragging. Research assumption A1 (an active tap sees native title-bar drags) and A16 (CGEvent.location is in global top-left points) are checked by the first human check.
Output: DragSession, Arranger pointer handling, InputTap, DragFramePoller, PreviewPanel, PreviewStyle, the Debug tap line, tests.
</objective>
