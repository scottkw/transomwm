## Shared Patterns

### Mode enums and engine input
**Source:** `Arranger.swift:27-28,419-421`; `GapPreference`. **Apply to:** both options.
The engine has no UserDefaults. `DragToDockMode`, `NewWindowsMode` and `DragOptionStrip` are public engine enums, String-backed for the first two. The Mac preference validates and sends them through `ArrangerInput`.

### One undo step, or nothing
**Source:** `Arranger.swift:1507-1521`, `Arranger+Commands.swift:236-249`. **Apply to:** `autoTile`, `dockFourth`.
```swift

```

### Room rules
**Source:** `Arranger.swift:1793-1798`, `Arranger+Commands.swift:240-244`. **Apply to:** all fourths. Collapse when zoom is on; otherwise refuse with `Self.noRoom`. Beep only on keyboard routes; a drop never beeps (`release` `:1868`). `autoTile` is silent.

**Source:** `DragSession.swift:56-74`. **Apply to:** `FourthCopy` (engine). Shell strings go in `MenuCopy`.

### Tap thread rules
**Source:** `InputTap.swift:50-55`, `GreenButton.swift`. **Apply to:** the strip. Pure rule, lock only to copy state, no AX, logging or file I/O in the callback.

### Persistent names
**Source:** `Hotkeys.swift:6-7`, `Command.swift:3-4`. **Apply to:** ten `Name`s and the `Command` case. Raw values and case names are permanent once shipped.

### Test style
Swift Testing with `@Suite struct`, `#expect`, `#require`. `@testable import` for internal rules, and `@MainActor` on suites of main-actor types (`GapPreferenceTests.swift:6`).
