## Phase Goal

**As a** new user, **I want to** install Transom with Homebrew and be guided through setup, **so that** it starts at login and keeps itself updated.

<objective>
"Download and Open" fetches the new release's disk image, verifies its SHA-256 digest, its Developer ID Team ID (S2K7P43927) and notarisation, and only then opens it; a Homebrew install is told to run `brew upgrade --cask transom` instead (D-10, SHIP-04, UI-SPEC Surface 3).

Verification runs in-process with the Security framework (probed in RESEARCH Pattern 4: status 0 for the real DMG, -67050 for a wrong team, -67061 for a corrupted copy), in gifsmith's order: digest, then signature, then quarantine, then open.
Output: `DMGDownloader`, `DMGVerifier`, the download states, the Homebrew branch, unit and env-gated tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub download hosts → Transom | The DMG bytes and every redirect are network input |
| Transom → Finder / Gatekeeper | Opening a disk image hands it to the system |
| Transom → user's Caches folder | Files written and deleted |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-23 | Tampering | Swapped or modified DMG (MITM, compromised CDN) | high | mitigate | HTTPS; exact-host allow-list on the asset URL and every redirect (≤5); byte count = asset size; SHA-256 = API digest; `SecStaticCodeCheckValidity` with team S2K7P43927 and `notarized`; delete on any failure, open nothing (`UpdateDownloadTests`, `UpdateRealDMGTests`) |
| T-09-24 | Tampering | Path traversal through the asset name | medium | mitigate | File name built from the validated version (`UpdateFeed.assetName`), never from JSON; files only inside the app-owned 0700 directory |

| T-09-26 | Denial of service | Deleting user files | low | mitigate | `clean()` removes only `Transom-*-universal.dmg` and `.part` in its own directory (`cleanRemovesOnlyTransomsOwnFiles`) |
| T-09-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed or added; CryptoKit and Security are system frameworks |
