## Phase Goal

**As a** Mac user, **I want to** grant Pane access and have it track and move every window, **so that** no slow app or lock screen can freeze or lose them.

<objective>
Give the user the debug surfaces CONTEXT promises: a live Tracked Windows list showing everything Pane knows about each window, the "Don't Arrange" exclusion toggle with its Never Arrange list, and a guarded Freeze test for checking that a frozen app cannot stall Pane.

Purpose: D-01 (debug menu: list, freeze test, don't-arrange), D-12 and WIN-08 (the user can list apps Pane never arranges; enforcement in Plan 13), the visible half of WIN-02/WIN-03/WIN-05 (rows, kinds, not-responding badges).
Output: ExclusionStore, TrackedWindowsModel/View/WindowController, FreezeTest, menu items, tests.
</objective>
