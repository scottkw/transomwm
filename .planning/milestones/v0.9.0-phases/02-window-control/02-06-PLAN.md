## Phase Goal

**As a** Mac user, **I want to** grant Pane access and have it track and move every window, **so that** no slow app or lock screen can freeze or lose them.

<objective>
Make tracking live and display-aware: windows and apps that appear after Pane starts are picked up through AX hints and NSWorkspace, refreshed with a cancel-latest debounce and a periodic safety sweep; every window knows which display (by UUID) it is on, through one tested coordinate-conversion boundary.

Purpose: WIN-02 ("including windows opened later"), the display half of WIN-04 (any display, any arrangement), D-09 (hints trigger cancellable refreshes), D-16 (observers on the app thread), D-18 (coordinates and display UUIDs).
Output: Coordinates, Displays, AppRegistry, RefreshScheduler, per-window observers, display support in the tracker and the fake, integration tests.
</objective>

Per D-09 and D-16, with the discretion values from 02-01-PLAN.md (75 ms per-pid debounce, 500 ms display debounce, 5 s sweep, 250 ms settle).

AXAppThread: keep a thread-confined cache `[UInt32: AXUIElement]` of window elements seen by `observe()`. Register app-level notifications kAXWindowCreatedNotification, kAXFocusedWindowChangedNotification, kAXMainWindowChangedNotification, kAXApplicationHiddenNotification, kAXApplicationShownNotification; when a window enters the cache register kAXUIElementDestroyedNotification, kAXWindowMovedNotification, kAXWindowResizedNotification, kAXWindowMiniaturizedNotification, kAXWindowDeminiaturizedNotification and kAXTitleChangedNotification on it. The callback resolves `windowID` by `CFEqual` against the cache (no IPC) and yields an `AXEventHint`. The Unmanaged refcon points at the thread object, which outlives its observers; `stop()` removes the observer's run-loop source, then drops window elements, then the app element, all on the thread.

RefreshScheduler (`@MainActor final class`): one pending `Task` per pid; `schedule(pid:after:)` cancels the pending task for that pid and starts a new sleep-then-refresh task (cancel-latest); `scheduleAll(after:)` likewise for a global refresh (used for display changes: replace Task 1's ad-hoc 500 ms Task with it); `startSweep(every:)` runs `refreshAll` on a repeating MainActor Task; `cancel(pid:)` on app quit.

AppRegistry (`@MainActor final class`): observes `NSWorkspace.shared.notificationCenter` didLaunchApplication, didTerminateApplication, didActivateApplication, didHideApplication, didUnhideApplication. It calls `onStart` for an app that is `.regular`, `isFinishedLaunching`, not Pane's own pid and not com.apple.loginwindow; an app that is not finished launching is retried on its activation and on each sweep (Pitfall 11). It re-checks activation policy on activation and sweep and calls `onStop` when an app stops being regular. Termination calls `onStop`.

AXWindowSystem: move app enumeration into AppRegistry; `onStart` creates the AXAppThread, emits `.appLaunched(pid:bundleID:)` and schedules a refresh; `onStop` stops the thread, cancels its scheduled refresh and, for termination, emits `.appTerminated(pid:)` (its windows stay tracked: closing them is Plan 09's two-source rule). Forward every hint to `scheduler.schedule(pid:)`; a focus hint whose windowID is tracked also emits `.windowFocused(ref)` after the refresh. After each per-pid refresh, if `tracker.hasPendingWindows(pid:)`, schedule a follow-up at `tracker.settleDelay`. Start the 5 s sweep in `start()`. Hide/unhide hints refresh that pid so state moves to `.absent` / back.

LiveTrackingTests (`.serialized`, `.enabled(if: IntegrationEnv.trusted, ...)`, `@MainActor`, each test `.timeLimit(.minutes(1))`), with `appFilter: { _, bundle in bundle == "unbundled:PaneFixtureApp" }`: (a) start AXWindowSystem first, then launch the fixture with `--window standard` → its window is in the inventory within 2 s and appLaunched was emitted; (b) `send("open standard")` → a windowCreated for the new id within 1 s; (c) `send("move 0 300 300")` → windowMoved with origin (300, 300) ± 1 pt within 1 s; (d) `send("minimize 0")` → windowStateChanged(.absent) within 1 s; (e) the window's displayUUID equals the UUID of the display Displays.current() reports for its frame; (f) terminating the fixture emits appTerminated within 2 s.
