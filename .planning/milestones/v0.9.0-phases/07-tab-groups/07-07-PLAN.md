## Phase Goal

**As a** Mac user, **I want to** group windows from any apps into one tabbed tile, **so that** related windows share space without overlapping.

<objective>
TABS-04: dragging a tab out of the strip turns into a normal window drag (D-10). The press on a strip is resolved in the tap pipeline and reaches the engine as a tab press (RESEARCH Pattern 7), so modifiers, the drop zones, the Group preview and the preview panel all work unchanged; the shell adds a click-through ghost and temporary Esc hotkeys.

Purpose: leaving a group by drag is the inverse of making one; using the existing pointer pipeline avoids a second drag implementation.

Output: `PointerEvent.pressTab`, `DragSession.origin` with the tear-off landing frame, `commitTearOff`, `.tearOffGhost` effect, `TearOffGhost.swift`, Esc hotkeys, copy.
</objective>
