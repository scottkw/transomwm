## Phase Goal

**As a** Mac user, **I want to** group windows from any apps into one tabbed tile, **so that** related windows share space without overlapping.

<objective>
TABS-06: the tab context menu with Close Tab and Move Out of Group (D-11), plus the same two actions as VoiceOver custom actions. Move Out uses the UI-SPEC landing rule (beside the group, else the other side, else cascade, then clamp); Close Tab reuses 07-05's close queue with one entry.

Purpose: a pointer user can leave a group or close one tab without dragging; VoiceOver users get the same reach.

Output: `TabAction.moveOut`/`.closeTab`, `moveOut` landing rule, context menu, custom actions, copy.
</objective>
