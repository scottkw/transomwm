Scan every `.swift` file with `grep -nE` using the extended regex `^[[:space:]]*(@[A-Za-z_]+[[:space:]]+)*import[[:space:]]+((typealias|struct|class|enum|protocol|let|var|func)[[:space:]]+)?(AppKit|Cocoa|SwiftUI)([[:space:].]|$)`.
