## Decision IDs used in this phase

01-CONTEXT.md lists its locked decisions as unnumbered bullets. Every plan in this phase cites them as D-01..D-23, numbered in the order they appear in `<decisions>`:

| ID | Decision (01-CONTEXT.md) |
|----|---------------------------|
| D-01 | Flat value tree `LayoutTree { root: NodeID?; nodes: [NodeID: Node] }`, `Node { split(axis, children, weights), panel(WindowRef), tabs(windows, selected) }` |
| D-02 | `NodeID` is a monotonic `UInt64` from an ID source, not a UUID |
| D-03 | Edits are `mutating` methods throwing typed `LayoutError`; `validate()` checks every invariant and runs after every edit in tests/debug |
| D-04 | Same-axis docking adds an n-ary sibling: new child `1/(n+1)`, others scaled `n/(n+1)` |
| D-05 | Removing a window redistributes its share proportionally among all siblings |
| D-06 | Normalise after every edit: collapse single-child splits, merge same-axis child splits, renormalise to sum 1 and clamp ≥ ε |
| D-07 | Gap-drag reweighing moves weight only between the two children either side of the boundary |
| D-08 | Pane's own `Rect`/`Size`/`Point` (Double, Codable, Equatable); no CoreGraphics types in the model API |
| D-09 | One global coordinate space: top-left origin, points |
| D-10 | `resolve(tree, in: Rect, mins: [WindowRef: Size], gap:)` with min-size water-filling |
| D-11 | Never overlap: windows that cannot fit are reported **unfit** (no rect), the rest share the space |
| D-12 | One gap value, between tiles and around the outer edge |
| D-13 | Rects rounded to whole points; last child in a split absorbs the remainder |
| D-14 | `DeskKey(displayUUID: String, spaceID: UInt64?)`; `World` maps DeskKey → Desk |
| D-15 | A Desk holds a tiled `LayoutTree` plus a floating `DesktopLayer` (windows + frames in desk coordinates) |
| D-16 | `WindowRef` = runtime identity `{ windowID, pid, bundleID }` + persisted hints `{ titleHint, axIdentifier?, creationOrder }` |
| D-17 | Lifecycle states present/absent/fullscreen/closed; absent/fullscreen keep their slot, excluded from resolve; only closed removes the slot |
| D-18 | Undo: every edit pushes a desk snapshot; 50 levels per desk |
| D-19 | JSON with `schemaVersion: 1`; newer fails with a clear error; older migrates step by step through a chain |
| D-20 | Drop zones: outer 25% band → edge dock; centre 50% → tab group; display edge bands → dock beside whole layout; constants |
| D-21 | Single `Package.swift`, `swift-tools-version: 6.2`, `.macOS(.v14)`, Swift 6 language mode |

LayoutTree.swift (D-01, D-03, D-17): Node and LayoutTree as in `<interfaces>`. `states` maps the identity of every window in the tree to its lifecycle state; insert stores `.present`. Implement Codable by hand: keys `root`, `nodes` (the dictionary, encoded as a JSON object via CodingKeyRepresentable) and `states` (an array of records `{ "window": WindowIdentity, "state": WindowState }` sorted by WindowIdentity, so output is deterministic and hints are not duplicated). `init(from:)` builds the tree and calls `validate()`; on failure it throws `DecodingError.dataCorrupted` whose context `underlyingError` is the LayoutError (Persistence unwraps it). TreeEdits.swift (D-03, D-04): every public edit works on a copy (`var next = self`), throws a typed LayoutError on bad input, assigns `self = next` only on success, then calls `assertValid()`. So a throwing edit leaves the tree unchanged. `insertRoot` throws `.treeNotEmpty` if root is non-nil, else creates `.panel(window)` with an ID from `ids.make()` and state `.present`. `insert(_:at:of:ids:)` throws `.duplicateWindow` if the window's identity is already in `states`, and `.nodeNotFound` for an unknown target. Otherwise, with `axis = edge.axis`, it applies the first matching rule: (1) the target's parent is a split with the same axis: insert a new panel immediately before the target (leading edge) or after it (trailing edge); the new child gets weight 1/(n+1) and every existing weight is multiplied by n/(n+1) (D-04). (2) The target is itself a split with the same axis: insert the new panel as its first child (leading edge) or last child (trailing edge) with the same 1/(n+1) rule. (3) Otherwise: replace the target in its parent slot (or as root) with a new split on `axis` whose children are [new, target] for a leading edge or [target, new] for a trailing edge, weights [0.5, 0.5], keeping the slot's weight in the parent. Throw `.splitFull(id, limit: maxChildren)` when a split already has maxChildren children. Task 2 adds the depth and node-count limits. These rules never create a same-axis child split.

Resolve.swift (D-10, D-12, D-13): `resolve(_:in:mins:gap:)` with the final signature. In this task it lays out by weights. Snap the area inward to whole points (ceil minX/minY, floor maxX/maxY). Round the gap to the nearest whole point. Inset the area by the gap on all four sides (D-12). Recursively split each split's rect along its axis: available length L = rect length minus gap × (k−1); child i < k−1 gets floor(weight_i × L); the last child gets L minus the sum of the others (D-13); children are separated by exactly the gap. Leaves (panel or tabs) record their rect in nodeRects, and every window of the leaf records it in windowRects. Splits also record their rect in nodeRects. unfit stays empty. An empty tree resolves to empty maps. Plan 03 adds min-size water-filling, unfit reporting, lifecycle exclusion and input validation inside this same function without changing its signature.

World.swift (D-14): Desk and World as in `<interfaces>`. `init(ids:desks:)` calls `validate()`, which validates every desk tree, checks that no window identity appears in two desks and that every NodeID in every tree is below `ids.next`.
