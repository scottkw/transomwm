## Phase Goal

**As a** Pane developer, **I want to** edit and resolve a nested tile layout in headless tests, **so that** every later feature rests on correct geometry.

<objective>
Complete the desk slice: each desk keyed by `DeskKey(displayUUID, spaceID?)` (D-14) holds a tiled tree plus a floating Desktop layer (D-15); every desk edit goes through one transactional funnel that pushes an undo snapshot, 50 levels per desk (D-18); and persistence is hardened: a newer schema fails clearly, older schemas migrate through a chain, corrupt or hostile files throw instead of crashing, and round-trips are byte-exact (D-19).

Purpose: covers ROADMAP success criteria 3 (desk + Desktop layer half) and 4 (JSON round-trip and undo).
Output: DesktopLayer.swift, Undo.swift, extended World.swift and Persistence.swift, three test suites.
</objective>
