How it works

Tile by dragging. Transom keeps it tidy.

01 drag title bar

Drop a window on an edge

Drag to a screen edge or to another window's edge. A preview shows the exact frame, and the window docks when you let go. A drop that can't fit the windows' minimum sizes is shown as blocked.

02 ⇧ float⌘ swap

Nest as deep as you like

Split any tile again, in any direction. Hold ⇧ to drop a window loose on the Desktop tile, or ⌘ over another tile to swap the two.

03 automatic

It stays arranged

Close or minimise a window and its neighbours fill the space. A minimised window comes back to its tile, and so does one leaving full screen.

Why Transom

Between snapping and scripting.

Snap tools put a window somewhere once and forget it. Keyboard tilers keep order but want a config file first. Transom keeps the order and lets your mouse set it up.

Layouts that rememberTiles are a tree, not a one-off frame. Windows that open, close, minimise or go full screen are put back where they belong.
Nothing to configureDrag to build a layout, and use the 30-odd hotkeys when your hands are on the keyboard. Every layout edit can be undone.
Floating when you want itNew windows open floating on the Desktop tile. Dock them when you're ready, or click the green button to toggle.
Free, for goodMIT licensed, native Swift, no account and no upsell.
Features

Careful with your windows.

A window manager moves every app you own, so Transom is built to fail safe.

Crash-safe restore

Quit and every moved window goes back on screen. After a crash, the next launch rescues stranded windows first, then re-applies the layout.

Layout restore

Relaunch Transom while your apps keep running and each layout comes back with the same windows in the same tiles.

Gaps

Drag the gap between two windows to resize both.

None 4 8 pt 12 16 24

Plays well with macOS

Transom spots Stage Manager, edge tiling and click-wallpaper-to-reveal-desktop, explains each conflict, and can put your original settings back.

Exclusions and pause

Mark any app Don't Arrange and Transom never moves it. Pause Arranging stops everything until you resume.

A frozen app can't stall it

Each app's Accessibility calls run off the main thread with a timeout, so one hung app never holds up the rest.

Per display and Space

Each display and each Space keeps its own layout. Full-screen Spaces are left alone.

Scriptable

Drive it from Shortcuts, Raycast or a shell.

open transom://restore open transom://toggle-desktop open transom://split-finder

Guided setup

A setup window walks you through the Accessibility grant, and if the grant goes stale Transom tells you how to fix it instead of nagging.

Hotkeys

Everything you can drag, you can type.

Every command lives under ⌃⌥⌘. Add ⇧ to move instead of focus. Floating windows snap to halves, thirds and quarters.

Privacy

It moves windows. It doesn't look inside them.

Transom needs one permission, Accessibility, and uses it only to read window positions and move them. The code is open, so you can check.

No screen captureTransom never reads window contents and doesn't ask for Screen Recording.
No network code at allThere is nothing in the app that can send data anywhere.
Window titles stay in memoryThe saved layout holds frames and app IDs, never titles, and only your account can read it.

Known limits in the pre-release+
  • Testing so far has used a single display. Treat a second display as unverified.
  • Hotkeys are fixed until the Settings window arrives.
  • Zoom, gestures, overview and tab groups are on the roadmap, not in the app yet.
  • Transom needs the Accessibility permission to move other apps' windows.
